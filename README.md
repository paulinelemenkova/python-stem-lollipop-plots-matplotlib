# Stem and Lollipop Plots with Python and Matplotlib

Python/Matplotlib script drawing stem (lollipop) plots of morphometric variables, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `stems.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `pylab`.

```
pip install matplotlib numpy pandas pylab
```
